KELANA-9 is a twin-prop air courier flying cargo between five named island airfields in a golden-hour archipelago, where every sortie is a small story of wind, weight, and timing. Five named missions structure the campaign: a ring course, a timed delivery, a night landing, a storm leg, and a precision heavy-cargo landing, each with its own briefing and scoring. Fuel and damage turn every flight into real decisions — push on with a dented airframe or play it safe and burn the margin. A chase view sweeps over procedural terrain beneath a lit instrument HUD, and every sound is synthesized in code, so the whole game runs offline from static files. `main.ts` hands the entry in by copying `game/` and `screenshots/` into the output directory and writing the dossier.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
